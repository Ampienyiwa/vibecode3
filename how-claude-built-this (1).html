How Claude built this

This page was made for Assignment 3 (vibe coding). I used Claude (Claude Code) to build an interactive network of funders that co-fund programs with the Doris Duke Foundation, and I guided it with my own prompts.

Tools used

Claude (Claude Code) wrote the page and the dataset. D3.js (v7) draws the force-directed graph. GitHub Pages hosts it. Headless Chrome was used by Claude to test the buttons.

Key prompts (in order)

1. Starting pointCan you see this: https://ddf-constellation.vercel.app/
2. Target designI shared a screenshot and said: "This is the page I am trying to build."
3. Data problem"How will I get this data?" → "I don't have it." Claude could not access the original site's data, so it rebuilt the data from public sources (foundation announcements, IRS 990-PF filings, annual reports).
4. RequirementsI shared the assignment requirements so the page met them: interactive, published on GitHub Pages, with an AI statement.
5. PublishingI created a GitHub repository and asked how to connect it, then uploaded the finished page and turned on GitHub Pages.
6. Usability checkI opened the live page and noticed the legend was hard to find at the bottom, and asked for it to be easy to see.

How accuracy was checked

Each funder and program comes from a public source. Endowments were found for 26 of 97 funders; the rest are drawn faint and labeled "endowment not found" rather than guessed. Program amounts that could not be confirmed show as dotted lines. The data is also in a spreadsheet in the repository so it can be checked.

How usability was checked

Claude tested the main interactions in a browser: clicking a funder, opening a program from the dropdown, the year slider, Play, Reset, zoom and area filters, with no errors. I then opened the live page myself and looked for anything confusing. A legend explains line thickness, circle size and colors.

Limits

This is a rebuild from public information, not DDF's official data, and it may contain errors or be out of date. Research as of Nov 24, 2026.
